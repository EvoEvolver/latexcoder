# Product

## Platform

web

## Users

Researchers and graduate students in research groups and labs who write LaTeX papers and theses together, including technically fluent authors who already use coding agents such as Claude Code and Codex. The person who decides to adopt it is often the one who self-hosts it for the group.

## Product Purpose

LaTeX Coder is an open-source (MIT), self-hosted collaborative LaTeX editor. It started as an attempt to clone Overleaf for a research group's own server; the team kept fixing what got in the way and ended up with a stronger tool. Success means a group deploys it and writes its papers there with coauthors, agents, and Git on the same source.

## Positioning

"Not another Overleaf. A better one." / 「不是另一个 Overleaf，是更好的那个。」

- Review (comments, replies, suggestions) is stored as LaTeX macros in the source, so it survives Git, ZIP exports, and agents.
- Every paper is a real Git repository: SSH clone, push, merge, conflicts on their own branch, restore.
- Coding agents edit the live paper through a checked protocol (download, edit locally, upload with the original content hash); a concurrent human edit makes the upload fail instead of being overwritten. Propose mode turns every agent change into a reviewable suggestion.
- View/Edit share links for guests, no account, no seat count.
- Plain files and Git repos on the group's own volume.

## Operating Context

Real-time collaborative editing in the browser with a PDF preview; compilation with full TeX Live (pdfLaTeX, XeLaTeX, LuaLaTeX via latexmk) or Tectonic on the group's own hardware. Deployed with one click on Railway or with Docker on any server. Interface in English, 中文, and 日本語.

## Capabilities and Constraints

- Hover previews for `\ref`/`\eqref` (equations and figures, across files) and `\cite`; ⌘-click to definitions.
- Character-level blame, SyncTeX both ways, per-chapter compilation, log-to-source error jumps, project search and replace, citation completion, history restore, usable on phones.
- Self-hosting is required: there is no hosted sign-up instance. Never imply one.
- Overleaf comparisons state only facts from Overleaf's public documentation (Git integration and collaborator limits tied to plans).

## Brand Commitments

- Name: LaTeX Coder. Logo: the L keycap (`docs/images/l-keycap.svg`).
- Slogan above is binding in both languages.
- Voice: direct, a little irreverent about Overleaf in the origin story, factual in comparisons.
- Closes by inviting feature requests through GitHub issues.

## Product Principles

1. Prove with the real interface, never with illustration of features it does not have.
2. Everything lives in the source: anything a collaborator or agent produces must survive Git.
3. The group owns its data and its server.
4. Agents are collaborators held to the same rules as people.
