# Surface brief: site/index.html (project website)

Mode: Persuade. Audience: researchers, grad students and lab admins who write LaTeX together, many already using coding agents. Action: deploy (Railway one click, or Docker) and star/read on GitHub; both carry equal weight with the "better than Overleaf" claim and agent editing. Proof: real product screenshots in site/assets, no invented testimonials or numbers. Close: invite feature requests via GitHub issues. Build path: code-led. Chosen sketch: .impeccable/mocks/decision/model-pick.html.

## Direction contract

THESIS: The site is a galley proof of a LaTeX paper, laid on the lab's desk and marked up by coauthors and an agent. It refuses the dev-tool landing page (centred headline, window screenshot, icon-card grid).

OWN-WORLD: A deep green desk blotter (#0f4f3b family) as ground; white proof sheets set in Computer Modern with line numbers, running heads and folios; red pencil for human marks, blue pencil for agent marks, handwritten margin notes; booktabs tables, numbered figures with captions, propositions, algorithm and listing blocks. Brand green appears on the blotter and the primary action only.

STORY: Visitors read a paper whose title is the slogan, see review marks living in the text, learn the story (we set out to clone Overleaf), the agent protocol, the features as figures, the comparison table, and leave to deploy or open an issue ("Open problems").

FIRST VIEWPORT: Nav on the blotter. One proof sheet, running head and line numbers, title "Not another Overleaf. A better one." in CM bold at ~80px, authors/affiliations line, abstract as the lede, Deploy on Railway and Star on GitHub set on the sheet under the abstract, red and blue margin notes in the outer margin anchored to text.

FORM: Galley Proof, IMPECCABLE'S PICK (rank 1 of 7), seed:fe65884c1543a963. Signature interaction: proof marks draw on in pencil once on load; pointing at a margin note highlights the text it marks.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
